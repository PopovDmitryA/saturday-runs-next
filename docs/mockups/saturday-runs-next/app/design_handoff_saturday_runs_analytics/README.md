# Handoff: Saturday Runs — единая аналитика (Сообщество + Личный кабинет)

## Overview
Высокоточный интерактивный прототип аналитической системы для **Saturday Runs** (run5k.run) — неофициального единого личного кабинета участника субботних парковых пробежек, агрегирующего данные из **5 вёрст**, **S95** и **parkrun**.

Прототип содержит две взаимосвязанные «вселенные» и три служебных раздела, переключаемых в одной шапке:
1. **Сообщество** — общая (общественная) статистика по всем платформам.
2. **Мой профиль** — персональная аналитика участника.
3. **Пробежки** — детальная таблица всех финишей с фильтрами/сортировкой.
4. **Привязки** — привязка профилей платформ и способы входа.
5. **О проекте** — миссия, дисклеймер, приватность, контакты.

Плюс: переключатель темы (свет/тьма) в шапке, адаптив (десктоп ↔ телефон), панель Tweaks, мобильный показ в iOS-фрейме (`mobile.html`).

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, реализованные в HTML/CSS/React (Babel inline JSX)**. Это прототип, демонстрирующий желаемый внешний вид и поведение, **а не продакшн-код для копирования напрямую**.

Задача: **воссоздать эти дизайны в существующем окружении целевого проекта**. Целевой кодовый продукт уже существует — это **React 19 + Vite + TypeScript** фронтенд (см. `frontend/src` основного репозитория Saturday Runs), с бэкендом FastAPI и REST API (`/api/dashboard`, `/api/runs`, `/api/volunteering`, `/api/sync/*`, профили). Дизайны нужно перенести в этот стек, используя его компоненты, роутинг (`AppShell`, `RequireAuth`), API-клиент (`lib/api.ts`) и устоявшиеся паттерны. CSS из прототипа можно адаптировать в существующий `index.css`/CSS-модули.

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы, состояния и анимации заданы точно. Воссоздавать пиксель-в-пиксель, но через библиотеки/паттерны кодовой базы. Данные в прототипе **вымышленные** — в продакшене брать из реальных API.

## Interactions & Behavior
- **Навигация разделов**: сегмент в шапке (`NavTabs`, скользящая `.seg-pill` — позиция/ширина измеряются по `offsetLeft/offsetWidth` активной кнопки, transition 0.45s `--ease`). На мобайле — фиксированная нижняя панель `.bottomnav` с иконками.
- **Смена раздела**: контент анимируется `@keyframes viewIn` (translateY 10→0, 0.5s); при смене `active` сбрасывается/взводится через `setTimeout(80)` для перезапуска count-up; скролл наверх.
- **Count-up** (`CountUp`): rAF-анимация 0→value, ease-out-cubic, ~1.4–1.5s; **фоллбек** `setTimeout(dur+250)` гарантирует финальное значение даже при throttling rAF.
- **Reveal** (`useInView`, IntersectionObserver, threshold 0.2, rootMargin `0 0 -8% 0`): добавляет класс/состояние для анимации графиков; **фоллбек** `setTimeout(500)`.
- **Графики**: линия — stroke-dashoffset; area — opacity; бары — scaleX/scaleY transform-origin; донат — stroke-dasharray. Все с задержками по индексу. Hover-тултипы (`.tooltip`, тёмные).
- **Тема**: `ThemeToggle` в шапке (солнце/луна) → `setTweak('theme', …)` → `data-theme` на `<html>` + пересчёт `--brand/--brand-ink/--vol` по выбранному акценту.
- **Фильтры/сортировка** (Пробежки): чистый React-стейт, `useMemo` для filtered/summary.
- **`#still`** (только для статичных скриншотов/reduced-motion): `window.__SR_STILL` + класс `.still` снимают transition/animation и сразу показывают финальные состояния.
- **prefers-reduced-motion: reduce** — обнуляет длительности, `.rise` сразу видим.

## State Management
Локальный React-стейт (без внешних стора):
- `App`: `tab` (раздел, начальный из hash), `active` (триггер count-up), tweaks-объект `t` (`useTweaks`).
- `RunsView`: `platFilter[]`, `query`, `sort {key,dir}`, `showTest`, `openRow`; `useMemo` filtered + summary.
- Карточки с переключателями (`GrowthCard`, `TopLocationsCard`, `LeaderboardCard`, `RecordsCard`): локальный `metric`/`tab`.
- `LinkedCard`: `open` (подтверждение отвязки), `syncing` (имитация обновления).
- В продакшене: заменить мок `window.SR` на данные из API (`/api/dashboard` → analytics, `/api/runs`, профили `/api/sync/status`). Структуру полей см. `data.js` + бэкенд-схемы (`schemas/dashboard.py`).

## Tweaks (панель настроек прототипа)
- **Тема**: light/dark.
- **Акцент**: 4 палитры (синий/бирюза/фиолет/малина) — меняют `--brand`.
- **Просмотр**: Десктоп / Телефон (класс `.shell.vm` — сворачивает приложение в рамку телефона: нижняя навигация, одна колонка).
- **Плотность**: compact/regular/comfy.

## Responsive behavior
- Брейкпоинты: `≤920px` (hero-stats 2 кол., cols-* сворачиваются, span-* full width), `≤820px` (навтабы скрыты → нижняя навигация `.bottomnav` fixed, отступ снизу), `≤560px` (компактная шапка, cols-2 → 1, hero-stats 2 кол.).
- Режим «Телефон» (Tweak) дублирует мобильную раскладку независимо от ширины окна — см. `.shell.vm` в `styles.css`.
- `mobile.html` — живой показ приложения в двух iOS-фреймах (Сообщество и Мой профиль).
